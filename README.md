# 五子棋

一个无需第三方依赖、可直接在浏览器运行的双人五子棋小游戏。

## 规则

- 棋盘为 15 × 15，黑棋先手，双方轮流在空位落子。
- 横向、纵向或斜向连成 5 子或更多即获胜。
- 棋盘下满仍无人获胜时为平局。本版本使用自由式规则，不包含 Renju 的禁手规则。

## 运行

需要 Python 3。无需安装 npm 依赖：

```sh
npm start
```

然后打开 <http://localhost:8000>。

## 验证

```sh
npm test
```

测试使用 Node.js 自带的测试运行器，覆盖棋盘初始化、四个连线方向、断点、长连和满盘判定。
